# UI/UX Pro Max Skill

This repository hosts the [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) skill bundle for Claude Code, installed under `.claude/skills/`.

Installed skills:

- **ui-ux-pro-max** — searchable design intelligence database (styles, color palettes, font pairings, UX guidelines, charts) across 22 tech stacks
- **ui-styling** — shadcn/ui, Tailwind CSS, and canvas-based visual design guidance
- **design** — brand identity, logos, corporate identity, banners, icons, social photos
- **design-system** — design token architecture and component specifications
- **brand** — brand voice, visual identity, and messaging frameworks
- **slides** — strategic HTML presentations with data visualization
- **banner-design** — multi-format creative banner design

Claude Code auto-discovers these via their `SKILL.md` files. Some scripts require Python 3.x; see `.claude/skills/ui-styling/scripts/requirements.txt` for optional dependencies.
